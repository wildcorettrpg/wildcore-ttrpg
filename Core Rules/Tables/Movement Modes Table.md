# Movement Modes Table

A Narrator's quick reference for how AP spent on movement translates to distance and consequences, per [Movement](../Encounters/Movement.md). All movement types share the same three effort tiers (1/2/3 AP); only the distance yielded and the fictional penalties change. "Base movement" is the character's full Movement Allowance (the distance granted by spending 1 AP on Walking).

See [Glossary](../../Glossary.md) for the definition of **[Vulnerable](../Conditions%20and%20Hazards/Conditions.md#vulnerable)**.

Each AP spent on a movement mode grants one full increment of that mode's distance unit. The unit varies by mode — Walking's unit is full base movement; Crawling's unit is ¼ base movement; Climbing and Wading's unit is ½ base movement; Flying's unit is full base movement.

| Mode                 | AP cost | Distance              | At base 30 ft | Penalties                                                                        |
| -------------------- | ------: | --------------------- | ------------: | -------------------------------------------------------------------------------- |
| Walking              |    1 AP | 1× base movement      |         30 ft | None                                                                             |
| Running              |    2 AP | 2× base movement      |         60 ft | −1 to attacks; −1 to Dodge                                                      |
| Sprinting            |    3 AP | 3× base movement      |         90 ft | −2 to attacks; −2 to Dodge; no Reactions                                        |
| Crawling (careful)   |    1 AP | ¼× base movement      |          5 ft | [Prone](../Conditions%20and%20Hazards/Conditions.md#prone)                                                                            |
| Crawling (hurried)   |    2 AP | ½× base movement      |         15 ft | [Prone](../Conditions%20and%20Hazards/Conditions.md#prone); −2 Reflex-based Opposition Checks                                         |
| Crawling (scramble)  |    3 AP | ¾× base movement      |         20 ft | [Prone](../Conditions%20and%20Hazards/Conditions.md#prone); −4 Reflex-based Opposition Checks; attacks against you gain +1 damage die |
| Climbing (steady)    |    1 AP | ½× base movement      |         15 ft | [Vulnerable](../Conditions%20and%20Hazards/Conditions.md#vulnerable)                                                                       |
| Climbing (fast)      |    2 AP | 1× base movement      |         30 ft | [Vulnerable](../Conditions%20and%20Hazards/Conditions.md#vulnerable); −2 Reflex-based Opposition Checks; may require checks                |
| Climbing (rush)      |    3 AP | 1½× base movement     |         45 ft | [Vulnerable](../Conditions%20and%20Hazards/Conditions.md#vulnerable); −4 Reflex-based Opposition Checks; automatic check on difficult surfaces |
| Wading (careful)     |    1 AP | ½× base movement      |         15 ft | None                                                                             |
| Wading (push)        |    2 AP | 1× base movement      |         30 ft | −2 Reflex-based Opposition Checks                                                |
| Wading (force)       |    3 AP | 1½× base movement     |         45 ft | −4 Reflex-based Opposition Checks                                                |
| Swimming (steady)    |    1 AP | ¼× base movement      |          5 ft | [Vulnerable](../Conditions%20and%20Hazards/Conditions.md#vulnerable)                                                                       |
| Swimming (hard)      |    2 AP | ½× base movement      |         15 ft | [Vulnerable](../Conditions%20and%20Hazards/Conditions.md#vulnerable); −2 Reflex-based Opposition Checks                                    |
| Swimming (desperate) |    3 AP | ¾× base movement      |         20 ft | [Vulnerable](../Conditions%20and%20Hazards/Conditions.md#vulnerable); −4 Reflex-based Opposition Checks; automatic check in rough water    |
| Flying (steady)      |    1 AP | 1× base movement      |         30 ft | [Vulnerable](../Conditions%20and%20Hazards/Conditions.md#vulnerable)                                                                       |
| Flying (fast)        |    2 AP | 2× base movement      |         60 ft | [Vulnerable](../Conditions%20and%20Hazards/Conditions.md#vulnerable); −2 to Dodge                                                          |
| Flying (dash)        |    3 AP | 3× base movement      |         90 ft | [Vulnerable](../Conditions%20and%20Hazards/Conditions.md#vulnerable); −4 to Dodge                                                          |

**Notes**

1. **[Vulnerable](../Conditions%20and%20Hazards/Conditions.md#vulnerable)**, per the Glossary definition, applies whenever a movement mode fully commits a character's attention and balance (climbing, swimming, flying) — they cannot oppose attacks with Reflex and automatically take hits while moving this way, though armor still mitigates.
2. This table is a reference, not a new rule — [Movement](../Encounters/Movement.md) remains the canonical description of how movement and AP interact.
