# Skills

## What a Skill Is

A skill is a discrete capability a character has learned and can bring to bear in play. Skills are binary — a character either has a skill or does not; there are no partial investments or incremental upgrades within a single skill. Each skill belongs to a skill tree, and trees represent a domain of training or a lineage path. Skills are purchased using Skill Points — see [Skill Points](../Characters/Skill%20Points.md) for how Skill Points are earned and spent.

## How Skills Work

Each skill does exactly what its description says — no more, no less. Skills stack: all applicable skill effects apply simultaneously. A skill applies when the situation matches its description, and provides no benefit when it doesn't. There is no universal rule that owning a skill automatically adds a die to related rolls — the skill's description defines its effect entirely.

## Skill Cost

Most skills cost **1 Skill Point** to purchase. Some skills cost more; the increased cost is stated in the skill's description. A character must meet all prerequisites before purchasing a skill, regardless of cost.

## Nodes and Skills

Skill trees contain two types of elements: **nodes** and **skills**. Nodes are structural organizers — they group related skills and gate access to the skills beneath them, but nodes do not require purchase. Skills are purchasable capabilities that require Skill Points to acquire and provide mechanical effects when purchased. A character may access any skill beneath a node without purchasing the node itself.

## Skill Trees and Prerequisites

Skills within a tree are organized from foundational to advanced. A character must own a skill's parent skill before purchasing any skill that branches from it. Some advanced skills have an additional investment threshold requirement — a minimum number of Skill Points spent within the same tree — stated in the skill's description. There is no requirement to purchase every skill in a tree; characters may follow any path through the tree as long as prerequisites are met.

## Using Skills

Skill Points are spent between sessions, outside of play. When a skill is purchased, the character immediately gains all benefits described in that skill. When a skill is lost through retraining, the character immediately loses all benefits and penalties granted by that skill — see [Skill Points](../Characters/Skill%20Points.md) for retraining rules.

## Skill Trees

Skill trees are organized into two categories: **Universal** and **Setting**. Universal trees are available to every character regardless of lineage or campaign setting. Attribute skills have no prerequisites and are always available. Setting trees are defined by the campaign setting and are not part of the core rules — they cover lineage paths and setting-specific capabilities, and campaign settings built on Velocity may define their own.
